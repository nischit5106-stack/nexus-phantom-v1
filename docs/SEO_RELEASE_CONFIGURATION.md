# Search and release configuration

Prepared association: Nischit Girish Kumar → NEXUS Research Initiative → PHANTOM. Four authored pages have unique titles/descriptions, Person and Organization relationships, a research/project page, a ScholarlyArticle paper page and a ProfilePage author page. The demo retains a separate synthetic-research description. Every meaningful image has alt text. NEXUS is explicitly an independent research identity.

The bundled source snapshot uses root-relative routes and Schema.org IDs. Open Graph and social-card fields are present. No domain, DOI, university affiliation, conference acceptance, GitHub repository or author social account is invented. The bundled source snapshot keeps portable metadata; deployment-specific canonical URLs and GitHub links are configured in the separate live site. The author-approved live site is https://nischit5106-stack.github.io/ and the public repository is https://github.com/nischit5106-stack/nexus-phantom-v1. The separate live deployment has configured canonical URLs, absolute structured-data IDs, an absolute social-card URL and GitHub crosslinks. `scripts/configure_site_metadata.py` remains available for local destination configuration. That script edits local files only and retains noindex/robots restrictions.

Indexing stays disabled: all pages have noindex/nofollow and robots.txt disallows crawling. No live sitemap is advertised while indexing remains disabled. `sitemap.paths.json` supplies the complete route list. Initial public deployment is author-approved and live. Separate explicit author approval is required before removing the noindex controls or submitting to search engines. This package does not claim that search engines have indexed the author's work.

The social card is an original vector composition incorporating the author-selected NEXUS mark; a PNG export is included for platforms that require raster Open Graph images. No live preview metadata service is contacted.
