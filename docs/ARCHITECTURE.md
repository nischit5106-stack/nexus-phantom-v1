# Architecture and evidence boundary

Observed events → source/support audit → matched construction → conditional population detection → separate graph reconstruction → support/alternatives/equivalence → human review with provenance.

The population detector requires an exact recurring schedule and scores coactivity relative to fixed-background, within-actor assignment permutations. The graph core instead uses unique semantic atoms, singleton-user burst support, fixed catalog candidates, pooled temporal evidence and conditional maximum comparison. These are distinct methods with distinct validation populations.

The investigation layer never converts a structural score into a causal probability. Supported non-alert, unsupported input and withheld attribution are separate states. The interface preserves complete scientific equivalence sets and missing provenance through filtering/export. No enforcement API exists. See the technical report for equations and the supplement for pseudocode/seeds/gates.

Public code includes the teaching example, aggregate plotting and interface. Full frozen detector/reconstruction code is excluded pending a separately cleared release; this package does not claim full experimental reproduction.
