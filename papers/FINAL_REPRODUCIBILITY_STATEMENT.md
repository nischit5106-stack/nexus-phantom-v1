# Reproducibility statement

Presentation reproduction uses released aggregate CSV/JSON, plotting scripts, LaTeX sources and bibliography. The synthetic teaching pipeline runs with Python's standard library and is explicitly not a reproduction of the frozen detector. The read-only dashboard renders curated synthetic fixtures and computes no scientific predictions.

Full historical reproduction requires separately authorized Deezer/ListenBrainz access, phase-specific runtime receipts, population construction and protected evaluator resources. Those are not bundled. Frozen research modules are inventoried privately but withheld from the public candidate pending ownership/licensing review; no clean-room reproduction of the accepted scientific method is claimed.

Obtain datasets independently from the original official sources. The repository's `docs/SOURCE_REPRODUCTION.md` gives authoritative citations, source/download pages, snapshots, date windows, eligibility conditions, expected schema, preprocessing and permitted checksum identifiers. Raw datasets are not mirrored. The guide distinguishes source preparation from exact reproduction requiring separately cleared code, population mappings and evaluator resources.

Phase 13 performs arithmetic checks on saved metric rows and hashes existing files. It never reruns scientific selection, construction, detectors, null draws or evaluation producers. A separately preregistered comparator study on nonfinal data is future work. Any scientific changes become PHANTOM v2. The consumed September final population cannot be reused as unseen evidence.
