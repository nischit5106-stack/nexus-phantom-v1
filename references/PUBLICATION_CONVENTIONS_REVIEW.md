# Fresh publication conventions review

Checked October 21, 2026. This is a presentation and positioning review, not an acceptance forecast. The final conference manuscript uses the preserved official acmart class in non-ACM mode for an independent report, without fabricated conference or DOI metadata. Actual submission must use the chosen track's current anonymous template.

| Primary reference | Useful convention | Application to FINAL |
|---|---|---|
| [RecSys 2026 call](https://recsys.acm.org/recsys26/call/) | Eight content pages for long papers; references separate; self-contained contribution | Aim for eight main pages; keep the final and causal-twin result in the main text. |
| [KDD 2026 research call](https://kdd2026.kdd.org/research-track-call-for-papers/) | Eight content pages; optional appendix; exact method and empirical contribution | State selectors and equations; do not use the appendix to hide the narrow support. |
| [The Web Conference 2027](https://www2027.thewebconf.org/research-track-papers/) | Eight main pages, twelve total; Web relevance and self-contained argument | Use as a current size reference; no submission or deadline eligibility is implied. |
| [WSDM 2026 call](https://wsdm-conference.org/2026/index.php/call-for-papers/) | Nine pages plus references/ethics; principled practical work | Keep ethics and intervention labels explicit. |
| [CIKM 2026 full papers](https://cikm2026.diag.uniroma1.it/full-research-papers/) | Ten content pages plus at most two references; reproducibility encouraged | Do not incorrectly apply an eight-page rule to all venues. |
| [ICWSM 2026](https://icwsm.org/2026/submit.html) | Eleven pages including references (eight recommended); mandatory checklist | An ACM-style file is not an ICWSM-ready submission. |

Recent-paper sample: [PISA, RecSys 2024](https://arxiv.org/html/2408.16578v1), [Graph Evidential Learning, KDD 2025](https://www.yunhaiwang.net/KDD2025/kdd_2025_GEL_Web/GEL_KDD25_camera.pdf), [SAGE, WSDM Companion 2026](https://www.amazon.science/publications/sage-scalable-automatic-gating-ensemble-for-confident-negative-harvesting-in-fraud-detection), [BAG, AAAI 2026](https://ojs.aaai.org/index.php/AAAI/article/view/38510), and [temporal/multiplex coordination, 2025 preprint](https://arxiv.org/html/2512.19677v1). Older CopyCatch, FRAUDAR and Pacheco provide essential method lineage rather than current template authority.

Titles pair a concrete method/domain with the actual task. Abstracts state problem, mechanism, evaluation units and principal finding; PHANTOM additionally needs label provenance and its failure region. Contributions should separate a new empirical record or implementation from existing randomization, MAD and graph concepts. Related Work should contrast tasks and information rather than list papers. Numbered equations define the statistic, null and assumptions before scores. Full-width diagrams are used where single-column labels would be too small; the conference version selects four main figures rather than squeezing all ten into it.

Limits and negative results belong beside positive results. Reproducibility distinguishes public presentation rebuilding from restricted source-data reruns. Ethics addresses real-user labeling, missing causal information and non-enforcement output. Supplementary material holds complete chronology, implementation edge cases, seeds and custody details. No wording, figures or performance numbers from other papers were copied as PHANTOM evidence.

AI policy is edition-specific. RecSys 2026 explicitly asks for extent/nature of generated material in acknowledgments; KDD 2026 additionally specifies submission-form disclosure. A newer ACM authorship page is indexed with different wording about writing assistance, but direct retrieval was blocked. Do not silently harmonize these policies. The prepared disclosure covers engineering, documentation and manuscript preparation, with human direction and accountability; recheck the exact future target before submission. The official template page was also blocked on this pass; the already bundled official acmart class and its notices were preserved.
